# 就餐项目 · 出差/外出单解析编码

> 链路：`HRIS_INS_DETAIL` → 解析 → `OA_DINING_EVECTION` → 按天展开 → `OA_DINING_DETAIL`
>
> 两步独立定时任务，可分别重跑：
> 1. **解析**：扫描未处理的出差单，解析 FORM_INFO 落解析表
> 2. **生成**：扫描 `HANDLE_FLAG='N'` 的解析记录，按天展开落底表

## 三、用餐窗口判断工具（核心逻辑）

```java
package com.ruoyi.project.ihr.util;

import com.ruoyi.project.ihr.constant.IhrDiningConstant;

import java.util.Calendar;
import java.util.Date;

/**
 * 用餐时间窗口判断工具
 *
 * 核心规则：出差时段与用餐窗口[12:30,13:00]是否相交
 *   相交充要条件：travelStart <= 13:00 且 travelEnd >= 12:30
 *
 * 该公式对首天/尾天/单天通用：
 *   - 首天：end视为当天23:59，第二个条件恒成立，退化为只判 start<=13:00
 *   - 尾天：start视为当天00:00，第一个条件恒成立，退化为只判 end>=12:30
 */
public class MealWindowUtil {

    private MealWindowUtil() {
    }

    /**
     * 判断某一天，出差时段是否与用餐窗口相交
     *
     * @param day         目标日期（只取年月日）
     * @param travelStart 出差开始时间（含时分）
     * @param travelEnd   出差结束时间（含时分）
     * @return true=相交（该天用餐时段人在出差中）
     */
    public static boolean isOverlapMealWindow(Date day, Date travelStart, Date travelEnd) {
        if (day == null || travelStart == null || travelEnd == null) {
            return false;
        }
        // 该天的用餐窗口起止
        Date mealStart = buildTime(day, IhrDiningConstant.MEAL_START_HOUR, IhrDiningConstant.MEAL_START_MINUTE);
        Date mealEnd   = buildTime(day, IhrDiningConstant.MEAL_END_HOUR,   IhrDiningConstant.MEAL_END_MINUTE);

        // 区间相交：travelStart <= mealEnd 且 travelEnd >= mealStart
        return !travelStart.after(mealEnd) && !travelEnd.before(mealStart);
    }

    /**
     * 构造指定日期的指定时刻
     */
    private static Date buildTime(Date day, int hour, int minute) {
        Calendar c = Calendar.getInstance();
        c.setTime(day);
        c.set(Calendar.HOUR_OF_DAY, hour);
        c.set(Calendar.MINUTE, minute);
        c.set(Calendar.SECOND, 0);
        c.set(Calendar.MILLISECOND, 0);
        return c.getTime();
    }

    /**
     * 日期归零到当天00:00:00
     */
    public static Date truncateDay(Date date) {
        if (date == null) {
            return null;
        }
        Calendar c = Calendar.getInstance();
        c.setTime(date);
        c.set(Calendar.HOUR_OF_DAY, 0);
        c.set(Calendar.MINUTE, 0);
        c.set(Calendar.SECOND, 0);
        c.set(Calendar.MILLISECOND, 0);
        return c.getTime();
    }

    /** 次日 */
    public static Date nextDay(Date date) {
        Calendar c = Calendar.getInstance();
        c.setTime(date);
        c.add(Calendar.DAY_OF_MONTH, 1);
        return c.getTime();
    }

    /** 是否同一天 */
    public static boolean isSameDay(Date d1, Date d2) {
        if (d1 == null || d2 == null) {
            return false;
        }
        return truncateDay(d1).getTime() == truncateDay(d2).getTime();
    }
}
```

## 六、service 实现（核心）

```java
package com.ruoyi.project.ihr.service.impl;

import com.alibaba.fastjson.JSON;
import com.alibaba.fastjson.JSONObject;
import com.ruoyi.common.utils.StringUtils;
import com.ruoyi.project.ihr.constant.IhrDiningConstant;
import com.ruoyi.project.ihr.domain.*;
import com.ruoyi.project.ihr.mapper.*;
import com.ruoyi.project.ihr.service.IOaDiningEvectionService;
import com.ruoyi.project.ihr.util.DiningDateUtil;
import com.ruoyi.project.ihr.util.MealWindowUtil;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.text.ParseException;
import java.text.SimpleDateFormat;
import java.util.ArrayList;
import java.util.Arrays;
import java.util.Date;
import java.util.List;

@Service
public class OaDiningEvectionServiceImpl implements IOaDiningEvectionService {
    private static final Logger log = LoggerFactory.getLogger(OaDiningEvectionServiceImpl.class);

    @Autowired private HrisInsDetailMapper    insDetailMapper;
    @Autowired private OaDiningEvectionMapper evectionMapper;
    @Autowired private OaDiningDetailMapper   diningDetailMapper;
    @Autowired private HrisStaffMapper        staffMapper;
    @Autowired private HrisScheduleMapper     scheduleMapper;

    // ==================== 步骤一：解析单据 ====================

    /**
     * 解析出差单
     * 说明：不按流程状态过滤，审批中/通过/驳回/取消的事件全部解析，
     *      单据状态变化才能同步更新到解析表，进而驱动就餐数据的生成或回滚。
     *      每个 PROCESS_ID 只取最新一条事件（SQL 中已处理）。
     */
    @Override
    @Transactional(rollbackFor = Exception.class)
    public int parseEvection() {
        List<HrisInsDetail> list = insDetailMapper.queryPendingParse(
                IhrDiningConstant.APPROVAL_TYPE_EVECTION,
                IhrDiningConstant.SETTING_NAME_EVECTION);
        if (list == null || list.isEmpty()) {
            log.info("出差单解析: 无待解析数据");
            return 0;
        }

        int cnt = 0;
        for (HrisInsDetail ins : list) {
            try {
                OaDiningEvection e = convert(ins);
                if (e != null) {
                    evectionMapper.upsertEvection(e);
                    cnt++;
                }
            } catch (Exception ex) {
                log.error("出差单解析失败: processId={}", ins.getProcessId(), ex);
            }
        }
        log.info("出差单解析完成: 共{}条", cnt);
        return cnt;
    }

    /**
     * HRIS_INS_DETAIL -> 出差解析表
     */
    private OaDiningEvection convert(HrisInsDetail ins) {
        if (StringUtils.isEmpty(ins.getFormInfo())) {
            log.warn("出差单解析: FORM_INFO为空 processId={}", ins.getProcessId());
            return null;
        }
        JSONObject form = JSON.parseObject(ins.getFormInfo());

        OaDiningEvection e = new OaDiningEvection();
        // 单据基础信息
        e.setProcessId(ins.getProcessId());
        e.setProcessCode(ins.getProcessCode());
        e.setProcessStatus(ins.getProcessStatus());
        e.setApprovalType(ins.getApprovalType());
        e.setSettingName(ins.getSettingName());
        e.setOperatorStatus(ins.getOperatorStatus());
        e.setApplicantId(ins.getApplicantId());
        e.setApplicantName(ins.getApplicantName());
        e.setApplyTime(ins.getApplyTime());
        e.setEndTime(ins.getEndTime());

        // 出差目的地
        JSONObject dest = form.getJSONObject(IhrDiningConstant.FIELD_DESTINATION);
        if (dest != null) {
            e.setDestinationId(dest.getString("dataId"));
            e.setDestinationName(dest.getString("dataName"));
        }
        // 是否需要停餐
        JSONObject stopType = form.getJSONObject(IhrDiningConstant.FIELD_STOP_TYPE);
        if (stopType != null) {
            e.setStopTypeId(stopType.getString("dataId"));
            e.setStopTypeName(stopType.getString("dataName"));
        }
        // 外地就餐公司（不停餐时该控件可能不存在，需判空）
        JSONObject company = form.getJSONObject(IhrDiningConstant.FIELD_DINING_COMPANY);
        if (company != null) {
            e.setDiningCompanyId(company.getString("dataId"));
            e.setDiningCompanyName(company.getString("dataName"));
        }
        // 具体停餐时间区间（仅方式二有值）
        JSONObject stopRange = form.getJSONObject(IhrDiningConstant.FIELD_STOP_RANGE);
        if (stopRange != null) {
            e.setStopStartDate(DiningDateUtil.parse(stopRange.getString("startTime")));
            e.setStopEndDate(DiningDateUtil.parse(stopRange.getString("endTime")));
            e.setStopDuration(stopRange.getBigDecimal("durationTime"));
        }
        e.setApplyReason(form.getString(IhrDiningConstant.FIELD_APPLY_REASON));
        // 出差起止时间：yyyy-MM-dd HH:mm
        e.setTravelStartTime(parseDateTime(form.getString(IhrDiningConstant.FIELD_START_TIME)));
        e.setTravelEndTime(parseDateTime(form.getString(IhrDiningConstant.FIELD_END_TIME)));

        // 判定是否总部员工
        boolean isHq = staffMapper.queryByStaffId(ins.getApplicantId()) != null;
        e.setIsHqStaff(isHq ? "Y" : "N");

        // 判定是否纳入统计
        checkValid(e, isHq);

        e.setHandleFlag(IhrDiningConstant.HANDLE_FLAG_NO);
        e.setDel("0");
        e.setCreateTime(new Date());
        e.setUpdateTime(new Date());
        return e;
    }

    /**
     * 是否纳入就餐统计
     * - 总部人员：直接纳入（算停餐）
     * - 非总部人员：须同时满足 目的地=集团本部 且 外地就餐公司=集团食堂（算用餐）
     */
    private void checkValid(OaDiningEvection e, boolean isHq) {
        if (e.getTravelStartTime() == null || e.getTravelEndTime() == null) {
            e.setIsValid("N");
            e.setInvalidReason("出差起止时间缺失");
            return;
        }
        if (StringUtils.isEmpty(e.getStopTypeId())) {
            e.setIsValid("N");
            e.setInvalidReason("未填写是否停餐");
            return;
        }
        if (isHq) {
            e.setIsValid("Y");
            return;
        }
        // 非总部人员：双条件校验
        boolean destOk = IhrDiningConstant.DESTINATION_HQ.equals(e.getDestinationId());
        boolean compOk = IhrDiningConstant.DINING_COMPANY_HQ.equals(e.getDiningCompanyId());
        if (destOk && compOk) {
            e.setIsValid("Y");
        } else {
            e.setIsValid("N");
            e.setInvalidReason("非总部人员，出差地点或就餐公司不满足条件: dest="
                    + e.getDestinationName() + ", company=" + e.getDiningCompanyName());
        }
    }

    // ==================== 步骤二：生成就餐明细 ====================

    @Override
    @Transactional(rollbackFor = Exception.class)
    public int generateDiningDetail() {
        List<OaDiningEvection> list = evectionMapper.queryPendingHandle();
        if (list == null || list.isEmpty()) {
            log.info("出差就餐明细生成: 无待处理数据");
            return 0;
        }

        int total = 0;
        for (OaDiningEvection e : list) {
            try {
                // 重新生成前先清理旧数据，保证幂等
                diningDetailMapper.deleteBySourceProcessId(e.getProcessId());

                // 单据失效（DENIED已驳回 / CANCEL已取消）：只清理不重建，实现回滚
                if (isInvalidStatus(e.getProcessStatus())) {
                    evectionMapper.updateHandleFlag(e.getId(),
                            IhrDiningConstant.HANDLE_FLAG_YES,
                            "单据状态[" + e.getProcessStatus() + "]已失效，已回滚就餐数据");
                    continue;
                }
                // 不纳入统计
                if (!"Y".equals(e.getIsValid())) {
                    evectionMapper.updateHandleFlag(e.getId(),
                            IhrDiningConstant.HANDLE_FLAG_YES, e.getInvalidReason());
                    continue;
                }

                List<OaDiningDetail> details = "Y".equals(e.getIsHqStaff())
                        ? buildForHqStaff(e)          // 总部人员：算停餐
                        : buildForExternalStaff(e);   // 非总部人员：算用餐

                for (OaDiningDetail d : details) {
                    diningDetailMapper.insertDetail(d);
                }
                total += details.size();
                evectionMapper.updateHandleFlag(e.getId(),
                        IhrDiningConstant.HANDLE_FLAG_YES, "生成明细" + details.size() + "条");
            } catch (Exception ex) {
                log.error("出差就餐明细生成失败: processId={}", e.getProcessId(), ex);
                evectionMapper.updateHandleFlag(e.getId(),
                        IhrDiningConstant.HANDLE_FLAG_ERROR, ex.getMessage());
            }
        }
        log.info("出差就餐明细生成完成: 共{}条", total);
        return total;
    }

    /**
     * 总部人员 —— 生成【停餐】记录
     * 需关联本人排班，仅工作日计入
     */
    private List<OaDiningDetail> buildForHqStaff(OaDiningEvection e) {
        List<OaDiningDetail> result = new ArrayList<OaDiningDetail>();
        String stopType = e.getStopTypeId();

        // 方式三：不停餐 —— 不产生任何停餐记录
        if (IhrDiningConstant.STOP_TYPE_NONE.equals(stopType)) {
            return result;
        }

        HrisStaff staff = staffMapper.queryByStaffId(e.getApplicantId());
        if (staff == null) {
            return result;
        }

        List<Date> stopDays;
        int priority;
        if (IhrDiningConstant.STOP_TYPE_BY_CUSTOM.equals(stopType)) {
            // 方式二：按具体停餐时间 —— 区间内全天停餐，无需判用餐窗口
            stopDays = listWorkingDays(e.getApplicantId(), e.getStopStartDate(), e.getStopEndDate());
            priority = IhrDiningConstant.PRIORITY_CUSTOM_RANGE;
        } else {
            // 方式一：按出差时间 —— 首尾天需判用餐窗口
            stopDays = listTravelStopDays(e);
            priority = IhrDiningConstant.PRIORITY_WHOLE_RANGE;
        }

        for (Date day : stopDays) {
            result.add(buildDetail(e, staff, day, IhrDiningConstant.DINING_TYPE_STOP,
                    IhrDiningConstant.STAFF_SCOPE_HQ, priority));
        }
        return result;
    }

    /**
     * 非总部人员 —— 生成【用餐】记录
     * 出差到总部即在总部食堂用餐；不关联个人排班，按集团公共工作日历筛
     */
    private List<OaDiningDetail> buildForExternalStaff(OaDiningEvection e) {
        List<OaDiningDetail> result = new ArrayList<OaDiningDetail>();
        String stopType = e.getStopTypeId();

        // 方式三：不停餐 —— 直接不在集团用餐
        if (IhrDiningConstant.STOP_TYPE_NONE.equals(stopType)) {
            return result;
        }

        List<Date> dineDays;
        int priority;
        if (IhrDiningConstant.STOP_TYPE_BY_CUSTOM.equals(stopType)) {
            // 方式二：具体停餐区间即在集团用餐区间
            dineDays = listPublicWorkingDays(e.getStopStartDate(), e.getStopEndDate());
            priority = IhrDiningConstant.PRIORITY_CUSTOM_RANGE;
        } else {
            // 方式一：按出差时间，首尾天判用餐窗口（含窗口=在总部吃）
            dineDays = listTravelDineDaysForExternal(e);
            priority = IhrDiningConstant.PRIORITY_WHOLE_RANGE;
        }

        for (Date day : dineDays) {
            OaDiningDetail d = buildDetail(e, null, day, IhrDiningConstant.DINING_TYPE_DINE,
                    IhrDiningConstant.STAFF_SCOPE_EXT, priority);
            d.setStaffName(e.getApplicantName());
            d.setStaffRole("非总部员工");
            result.add(d);
        }
        return result;
    }

    /**
     * 方式一（总部人员）：按出差时间推导停餐日
     * 首尾天判用餐窗口相交，中间天必然相交；再按本人排班筛工作日
     */
    private List<Date> listTravelStopDays(OaDiningEvection e) {
        List<Date> result = new ArrayList<Date>();
        // 先取出差区间内本人的所有工作日
        List<Date> workingDays = listWorkingDays(e.getApplicantId(),
                e.getTravelStartTime(), e.getTravelEndTime());

        for (Date day : workingDays) {
            // 用餐窗口相交才算停餐（首尾天可能不相交，中间天必然相交）
            if (MealWindowUtil.isOverlapMealWindow(day, e.getTravelStartTime(), e.getTravelEndTime())) {
                result.add(day);
            }
        }
        return result;
    }

    /**
     * 方式一（非总部人员）：按出差时间推导在总部用餐日
     * 逻辑同上，但结论相反：相交=在总部食堂用餐
     */
    private List<Date> listTravelDineDaysForExternal(OaDiningEvection e) {
        List<Date> result = new ArrayList<Date>();
        List<Date> workingDays = listPublicWorkingDays(e.getTravelStartTime(), e.getTravelEndTime());
        for (Date day : workingDays) {
            if (MealWindowUtil.isOverlapMealWindow(day, e.getTravelStartTime(), e.getTravelEndTime())) {
                result.add(day);
            }
        }
        return result;
    }

    /**
     * 取某人某区间内的工作日（关联本人排班）
     */
    private List<Date> listWorkingDays(String staffId, Date start, Date end) {
        if (staffId == null || start == null || end == null) {
            return new ArrayList<Date>();
        }
        return scheduleMapper.queryWorkingDays(staffId,
                MealWindowUtil.truncateDay(start), MealWindowUtil.truncateDay(end));
    }

    /**
     * 取某区间内的集团公共工作日（当天有总部在职人员上班即为工作日）
     * 用于非总部人员——其不在排班表中，无法按个人取排班
     */
    private List<Date> listPublicWorkingDays(Date start, Date end) {
        if (start == null || end == null) {
            return new ArrayList<Date>();
        }
        return scheduleMapper.queryPublicWorkingDays(
                MealWindowUtil.truncateDay(start), MealWindowUtil.truncateDay(end));
    }

    /**
     * 构造一条就餐明细
     */
    private OaDiningDetail buildDetail(OaDiningEvection e, HrisStaff staff, Date day,
                                       String diningType, String scope, int priority) {
        OaDiningDetail d = new OaDiningDetail();
        if (staff != null) {
            d.setStaffId(staff.getStaffId());
            d.setStaffNo(staff.getStaffNo());
            d.setStaffName(staff.getStaffName());
            d.setDepartmentId(staff.getDepartmentId());
            d.setDepartmentName(staff.getDepartmentName());
            d.setPrDepartmentId(staff.getPrDepartmentId());
            d.setPrDepartmentName(staff.getPrDepartmentName());
        }
        d.setDiningDate(MealWindowUtil.truncateDay(day));
        d.setDiningType(diningType);
        d.setStaffScope(scope);
        d.setDiningNum(1);
        d.setSourceType(IhrDiningConstant.SOURCE_TYPE_EVECTION);
        d.setSourceProcessId(e.getProcessId());
        d.setSourceProcessCode(e.getProcessCode());
        // 审批中与已通过都会生成明细，报表按此字段选择统计口径
        d.setSourceStatus(e.getProcessStatus());
        d.setPriorityLevel(priority);
        d.setSourceApplyTime(e.getApplyTime());
        d.setIsEffective("Y");
        d.setDel("0");
        d.setCreateTime(new Date());
        d.setUpdateTime(new Date());
        return d;
    }

    /** 是否为需回滚的失效状态 */
    private boolean isInvalidStatus(String status) {
        return status != null
                && Arrays.asList(IhrDiningConstant.INVALID_STATUS).contains(status);
    }

    /** 解析 yyyy-MM-dd HH:mm */
    private Date parseDateTime(String str) {
        if (StringUtils.isEmpty(str)) {
            return null;
        }
        try {
            return new SimpleDateFormat(IhrDiningConstant.DATETIME_PATTERN).parse(str);
        } catch (ParseException ex) {
            log.warn("出差时间解析失败: {}", str);
            return null;
        }
    }
}
```

### 9.3 数据源过滤条件的修正（重要）

**问题**：最初 `queryPendingParse` 带了过滤条件
`AND (PROCESS_STATUS = 'PASS' OR OPERATOR_STATUS = 'createProcess')`，
导致驳回事件（`PROCESS_STATUS='DENIED'`、`OPERATOR_STATUS='deniedProcess'`）
与取消事件两个条件都不满足，**根本查不出来**。
后果：解析表的状态永远停留在审批中，`generateDiningDetail` 的回滚分支没有机会触发，
已生成的停餐数据会一直残留，食堂据此少备餐。

**修正**：去掉状态过滤，只按单据类型筛选；同时每个 `PROCESS_ID` 只取最新一条事件。
这也与项目既定原则一致——**入口全量收，状态判断下沉到处理环节**。

| 位置 | 修改内容 |
|---|---|
| `HrisInsDetailMapper.xml` 的 `queryPendingParse` | 删除 `PROCESS_STATUS`/`OPERATOR_STATUS` 过滤条件；改用 `ROW_NUMBER() OVER (PARTITION BY PROCESS_ID ORDER BY RECEIVE_TIME DESC, ID DESC)` 取每单最新事件 |
| `OaDiningEvectionServiceImpl.parseEvection` | 仅补充方法注释，逻辑无需改动 |
| `OaDiningEvectionServiceImpl.generateDiningDetail` | 仅将失效分支的日志改为输出具体状态，逻辑无需改动（原本已支持回滚） |
| Java 接口、实体、其余 SQL | 无需改动 |

**为什么要取最新一条事件**：同一张单会推送 createProcess、staffApproveProcess、deniedProcess 等多条事件。
若逐条 upsert，一是重复更新浪费，二是事件乱序到达时（重推/补推），
后处理的旧事件会把新状态覆盖回去——例如已是 `DENIED`，又来一条早先的 `createProcess`，
状态被改回审批中，回滚就失效了。

> **性能提示**：该 SQL 每次全量扫描出差单。当前数据量小无影响；
> 后续量大时可加时间范围限制（如仅处理近 N 天有新事件的单据），
> 或在 `HRIS_INS_DETAIL` 增加"已解析"标记做增量。

### 9.4 设计说明

1. **幂等**：`generateDiningDetail` 每次先 `deleteBySourceProcessId` 再插入，重跑不会重复。
   1.1 **插入方式采用循环单条，不可用 `INSERT ALL`**：Oracle 的 `INSERT ALL` 中 `SEQUENCE.NEXTVAL`
   对整条语句只求值一次，所有 INTO 分支拿到同一个 ID，一张单据生成多天明细时必然
   `ORA-00001` 违反主键唯一约束（表现为：单天单据成功、多天单据失败）。
   本表一张单仅几天到十几条明细，循环单条插入性能完全够用。
2. **回滚**：单据状态为 `DENIED`（已驳回）或 `CANCEL`（已取消，涵盖撤回/作废/撤销/删除）时只删不建。
   典型链路：单据先以 `createProcess` 被解析并生成停餐数据 → 审批人驳回 → 推来 `DENIED` 事件 → upsert 将状态更新为 `DENIED` 且 `HANDLE_FLAG` 重置为 `N` → 下次 generate 命中失效分支，数据被清除。
3. **方式二不判用餐窗口**：员工已明确指定停餐日期，整天停餐，无需再判首尾时刻。
4. **冲突收敛**：`refreshEffective` 单独提供，可在所有单据类型都解析完后统一执行，本次出差单可先不调用（无冲突时全部 `IS_EFFECTIVE='Y'`）。
5. **非总部人员无 STAFF_ID**：`refreshEffective` 中已用 `STAFF_ID IS NOT NULL` 排除，避免外部人员被误收敛。
6. **审批中与已通过都生成明细，统计口径由报表决定**：
   底表 `SOURCE_STATUS` 记录来源单据状态，报表按需筛选——
   - `SOURCE_STATUS = 'PASS'` → 已通过的**确定值**
   - `SOURCE_STATUS IN ('PASS','INITIATE')` → 含审批中的**预估值**（食堂提前备餐用）

   因 `generateDiningDetail` 先删后建，单据由审批中转为通过时该字段自动刷新，无需额外维护。
   建议报表同时展示差异，如"明日预计停餐 12 人（其中 3 人待审批）"，便于行政判断数据确定性。
