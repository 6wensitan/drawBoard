## 一、企业应用API/审批相关/OA回调接口规范/发起和审批单据后同步数据（这里我

请求地址：{baseUrl}/v1/workflow/webhook/submit

```
baseUrl:流程设置中 第四步高级设置中输入的《数据同步接口地址》
```

请求方式：POST

数据格式：application/json

### 接口说明

 将提交的表单数据回调第三方系统提供的接口同步数据至第三方系统。

```
注：接口严格按照文档执行，若配置了接口但返回格式错误将导致同步异常
```

**接口允许建立连接超时时间10s，建立连接成功后从服务器读取超时时间5s，如同一模版异常10次将被熔断接口半小时，半小时后重试，无异常恢复，异常继续熔断半小时**

- 成功：数据同步成功
- 失败：审批同步失败OA系统将异步重试，10次报错后将会向钉钉报警

##### header token生成方式 md5

1.三个参数拼接 `固定值 + 时间戳 + 公司id` 固定值请咨询后对接。 2.拼接后数据进行 MD5加密

举例说明： 客户唯一身份标识为abcd，当前时戳为1616119929342，则合成的数据为:{固定值}1616119929342abcd

签名加密工具类

> 示例代码以java为例，非java用户需要根据此算法编写自己相应语言的工具类。

```java
import lombok.extern.slf4j.Slf4j;
import java.math.BigInteger;
import java.security.MessageDigest;

@Slf4j
public class Md5Util {

    public static String getMd5String(String encryptData) {
        try {
            MessageDigest md = MessageDigest.getInstance("MD5");
            md.update(encryptData.getBytes());
            return new BigInteger(1, md.digest()).toString(16);
        } catch (Exception e) {
            log.error("getMD5String error : {}", e.getMessage());
            return null;
        }
    }
}
```

##### param token生成方式 jwt

```
注：使用此方式进行强验证时，需要找对应实施经理或者客户成功童鞋申请技术支持
```

1.SecretKey：沟通后配置，未提供 默认为租户在i人事系统的公司ID 2.expiresAt: 令牌过期时间为 10 分钟 3.businessCode：ihr

> 示例代码以java为例，非java用户需要根据此算法编写自己相应语言的工具类。

```java
import cn.hutool.jwt.JWT;

@Slf4j
public class JwtUtil {

    public static String getJwtsString(String secretKey) {
        try {
            // 设置当前时间作为发行时间（iat）
            Date issuedAt = new Date();
            // 设置令牌过期时间为 10 分钟后
            Date expiresAt = new Date(issuedAt.getTime() + (600 * 1000));
            // 构建 JWT Token
            return JWT.create()
                    .setPayload("businessCode", "ihr")
                    .setIssuedAt(issuedAt).setExpiresAt(expiresAt)
                    .setKey(secretKey.getBytes()).sign();
        } catch (Exception e) {
            log.error("getJwtsString error : {}", e.getMessage());
            return null;
        }
    }
}
```
