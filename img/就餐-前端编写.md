# 就餐项目-前端

## 就餐明细页

前端页面代码：

### vue页面:

```vue
<template>
  <div class="app-container dining-report" :class="{ 'is-mobile': isMobile }">

    <!-- 搜索区：移动端标签置顶、控件占满宽度 -->
    <el-form :model="queryParams" ref="queryForm" size="small"
             :inline="!isMobile"
             :label-position="isMobile ? 'top' : 'right'"
             :label-width="isMobile ? 'auto' : '82px'"
             class="search-form">
      <el-form-item label="就餐日期" prop="dateRange">
        <el-date-picker
          v-model="dateRange"
          type="daterange"
          value-format="yyyy-MM-dd"
          range-separator="至"
          start-placeholder="开始日期"
          end-placeholder="结束日期"
          :clearable="false"
          :picker-options="pickerOptions"
          :style="ctrlStyle(240)"
          @change="handleDateChange"
        />
      </el-form-item>
      <el-form-item label="工号" prop="staffNo">
        <el-input v-model="queryParams.staffNo" placeholder="支持模糊查询" clearable
                  :style="ctrlStyle(150)" @keyup.enter.native="handleQuery" />
      </el-form-item>
      <el-form-item label="姓名" prop="staffName">
        <el-input v-model="queryParams.staffName" placeholder="支持模糊查询" clearable
                  :style="ctrlStyle(130)" @keyup.enter.native="handleQuery" />
      </el-form-item>
      <el-form-item label="就餐状态" prop="diningType">
        <el-select v-model="queryParams.diningType" placeholder="全部" clearable :style="ctrlStyle(110)">
          <el-option label="就餐" value="DINE" />
          <el-option label="停餐" value="STOP" />
        </el-select>
      </el-form-item>

      <template v-if="showMore">
        <el-form-item label="二级部门" prop="prDepartmentId">
          <el-select v-model="queryParams.prDepartmentId" placeholder="全部" clearable filterable
                     :style="ctrlStyle(160)" @change="handlePrDeptChange">
            <el-option v-for="d in deptOptions" :key="d.id" :label="d.name" :value="d.id" />
          </el-select>
        </el-form-item>
        <el-form-item label="所属部门" prop="departmentId">
          <el-select v-model="queryParams.departmentId" placeholder="全部" clearable filterable
                     :style="ctrlStyle(160)">
            <el-option v-for="d in subDeptOptions" :key="d.id" :label="d.name" :value="d.id" />
          </el-select>
        </el-form-item>
        <el-form-item label="人员范围" prop="staffScope">
          <el-select v-model="queryParams.staffScope" placeholder="全部" clearable :style="ctrlStyle(120)">
            <el-option label="内部员工" value="HQ" />
            <el-option label="外部人员" value="EXTERNAL" />
          </el-select>
        </el-form-item>
        <el-form-item label="数据来源" prop="sourceType">
          <el-select v-model="queryParams.sourceType" placeholder="全部" clearable :style="ctrlStyle(140)">
            <el-option v-for="(label, key) in sourceTypeMap" :key="key" :label="label" :value="key" />
          </el-select>
        </el-form-item>
      </template>

      <el-form-item class="search-btns">
        <el-button type="primary" icon="el-icon-search" size="mini"
                   v-hasPermi="['dining:report:list']" @click="handleQuery">搜索</el-button>
        <el-button icon="el-icon-refresh" size="mini" @click="resetAll">重置</el-button>
        <el-button type="text" size="mini" @click="showMore = !showMore">
          {{ showMore ? '收起' : '更多筛选' }}
          <i :class="showMore ? 'el-icon-arrow-up' : 'el-icon-arrow-down'"></i>
        </el-button>
      </el-form-item>
    </el-form>

    <!-- 汇总卡片：移动端每行2个，桌面端一行铺开 -->
    <el-row :gutter="12" class="summary-row" v-loading="summaryLoading"
            v-hasPermi="['dining:report:summary']">
      <el-col :xs="12" :sm="8" :md="8" :lg="4" v-for="card in summaryCards" :key="card.key">
        <div class="summary-card"
             :class="[card.key, {
               'is-clickable': !!card.filter,
               'is-active': activeCard === card.key
             }]"
             @click="handleCardClick(card)">
          <div class="card-label">
            {{ card.label }}
            <!-- 移动端版面有限，说明文字改为点击图标弹出，避免用户无从得知统计口径 -->
            <i v-if="card.tip && isMobile" class="el-icon-question card-help"
               @click.stop="showTip(card)"></i>
            <i v-if="activeCard === card.key" class="el-icon-close card-clear" title="取消筛选"></i>
          </div>
          <div class="card-value">
            {{ summary[card.key] || 0 }}
            <span class="card-unit">人</span>
          </div>
          <div class="card-tip" v-if="card.tip && !isMobile">{{ card.tip }}</div>
        </div>
      </el-col>
    </el-row>

    <el-alert
      v-if="summary.pendingNum > 0"
      class="pending-alert"
      type="warning"
      :closable="false"
      show-icon>
      当前统计含 <b>{{ summary.pendingNum }}</b> 人次的单据仍在审批中，数据可能变动
    </el-alert>

    <!-- 操作栏：移动端按钮平分一行 -->
    <div class="toolbar" :class="{ 'toolbar-mobile': isMobile }">
      <el-button type="warning" plain icon="el-icon-download" size="mini"
                 v-hasPermi="['dining:report:export']" @click="handleExportDaily">
        每日报餐明细
      </el-button>
      <el-button type="warning" plain icon="el-icon-download" size="mini"
                 v-hasPermi="['dining:report:exportOuterDiner']" @click="handleExportOuter">
        外部人员用餐
      </el-button>
      <el-button type="warning" plain icon="el-icon-download" size="mini"
                 v-hasPermi="['dining:report:exportStaffMatrix']" @click="handleExportMatrix">
        员工就餐天数
      </el-button>
      <!-- 该提示说明两套统计口径的差异，移动端同样需要，仅缩小字号另起一行 -->
      <div class="toolbar-tip" :class="{ 'tip-mobile': isMobile }">
        <i class="el-icon-info"></i>
        每日报餐明细含审批中单据；员工就餐天数仅统计已通过单据
      </div>
    </div>

    <!-- 桌面端：表格 -->
    <el-table v-if="!isMobile" v-loading="loading" :data="detailList" border stripe size="small"
              :header-cell-style="{ background: '#f5f7fa', color: '#606266' }">
      <el-table-column label="就餐日期" prop="diningDate" width="110" align="center">
        <template slot-scope="scope">{{ parseTime(scope.row.diningDate, '{y}-{m}-{d}') }}</template>
      </el-table-column>
      <el-table-column label="工号" prop="staffNo" width="140" align="center">
        <template slot-scope="scope">
          <span v-if="scope.row.staffNo">{{ scope.row.staffNo }}</span>
          <span v-else class="text-muted">—</span>
        </template>
      </el-table-column>
      <el-table-column label="姓名" prop="staffName" width="100" align="center" show-overflow-tooltip />
      <el-table-column label="部门" prop="departmentName" min-width="130" show-overflow-tooltip>
        <template slot-scope="scope">
          <span v-if="scope.row.departmentName">{{ scope.row.departmentName }}</span>
          <span v-else class="text-muted">—</span>
        </template>
      </el-table-column>
      <el-table-column label="二级部门" prop="prDepartmentName" min-width="120" show-overflow-tooltip>
        <template slot-scope="scope">
          <span v-if="scope.row.prDepartmentName">{{ scope.row.prDepartmentName }}</span>
          <span v-else class="text-muted">—</span>
        </template>
      </el-table-column>
      <el-table-column label="就餐状态" prop="diningType" width="100" align="center">
        <template slot-scope="scope">
          <el-tag :type="scope.row.diningType === 'STOP' ? 'danger' : 'success'" size="mini" effect="light">
            {{ scope.row.diningType === 'STOP' ? '停餐' : '就餐' }}
            <span v-if="scope.row.diningNum > 1">×{{ scope.row.diningNum }}</span>
          </el-tag>
        </template>
      </el-table-column>
      <el-table-column label="人员范围" prop="staffScope" width="90" align="center">
        <template slot-scope="scope">
          <el-tag :type="scope.row.staffScope === 'HQ' ? '' : 'warning'" size="mini" effect="plain">
            {{ scope.row.staffScope === 'HQ' ? '内部' : '外部' }}
          </el-tag>
        </template>
      </el-table-column>
      <el-table-column label="身份" prop="staffRole" width="110" align="center" show-overflow-tooltip>
        <template slot-scope="scope">
          <span v-if="scope.row.staffRole">{{ scope.row.staffRole }}</span>
          <span v-else class="text-muted">—</span>
        </template>
      </el-table-column>
      <el-table-column label="数据来源" min-width="180" show-overflow-tooltip>
        <template slot-scope="scope">
          <template v-if="scope.row.sourceType">
            <el-tag size="mini" effect="plain" :type="sourceTagType(scope.row.sourceType)">
              {{ sourceTypeMap[scope.row.sourceType] || scope.row.sourceType }}
            </el-tag>
            <span class="source-code">{{ scope.row.sourceProcessCode }}</span>
          </template>
          <span v-else class="text-muted">默认就餐</span>
        </template>
      </el-table-column>
      <el-table-column label="单据状态" prop="sourceStatus" width="100" align="center">
        <template slot-scope="scope">
          <el-tag v-if="scope.row.sourceStatus === 'INITIATE'" type="warning" size="mini">审批中</el-tag>
          <el-tag v-else-if="scope.row.sourceStatus === 'PASS'" type="success" size="mini" effect="plain">已通过</el-tag>
          <span v-else class="text-muted">—</span>
        </template>
      </el-table-column>
    </el-table>

    <!-- 移动端：卡片列表。表格列多，手机上横向滚动难以阅读，改为卡片 -->
    <div v-else class="m-list" v-loading="loading">
      <div class="m-card" v-for="(item, idx) in detailList" :key="idx">
        <div class="m-card-hd">
          <div class="m-hd-left">
            <span class="m-name">{{ item.staffName }}</span>
            <el-tag :type="item.staffScope === 'HQ' ? '' : 'warning'" size="mini" effect="plain">
              {{ item.staffScope === 'HQ' ? '内部' : '外部' }}
            </el-tag>
          </div>
          <el-tag :type="item.diningType === 'STOP' ? 'danger' : 'success'" size="mini" effect="light">
            {{ item.diningType === 'STOP' ? '停餐' : '就餐' }}
            <span v-if="item.diningNum > 1">×{{ item.diningNum }}</span>
          </el-tag>
        </div>
        <div class="m-card-bd">
          <div class="m-row">
            <span class="m-label">日期</span>
            <span class="m-val">{{ parseTime(item.diningDate, '{y}-{m}-{d}') }}</span>
          </div>
          <div class="m-row" v-if="item.staffNo">
            <span class="m-label">工号</span>
            <span class="m-val">{{ item.staffNo }}</span>
          </div>
          <div class="m-row" v-if="item.departmentName || item.prDepartmentName">
            <span class="m-label">部门</span>
            <span class="m-val">{{ item.departmentName || item.prDepartmentName }}</span>
          </div>
          <div class="m-row" v-if="item.staffRole">
            <span class="m-label">身份</span>
            <span class="m-val">{{ item.staffRole }}</span>
          </div>
          <div class="m-row">
            <span class="m-label">来源</span>
            <span class="m-val">
              <template v-if="item.sourceType">
                <el-tag size="mini" effect="plain" :type="sourceTagType(item.sourceType)">
                  {{ sourceTypeMap[item.sourceType] || item.sourceType }}
                </el-tag>
                <span class="source-code">{{ item.sourceProcessCode }}</span>
                <el-tag v-if="item.sourceStatus === 'INITIATE'" type="warning" size="mini">审批中</el-tag>
              </template>
              <span v-else class="text-muted">默认就餐</span>
            </span>
          </div>
        </div>
      </div>
      <div class="m-empty" v-if="!loading && detailList.length === 0">暂无数据</div>
    </div>

    <pagination
      v-show="total > 0"
      :total="total"
      :page.sync="queryParams.pageNum"
      :limit.sync="queryParams.pageSize"
      :layout="isMobile ? 'total, prev, pager, next' : 'total, sizes, prev, pager, next, jumper'"
      @pagination="getList"
    />
  </div>
</template>

<script>
import { listDiningDetail, getDiningSummary, listDeptOptions, listSubDeptOptions, exportDiningFile } from '@/api/oa/report'

export default {
  name: 'DiningReport',
  data() {
    return {
      loading: false,
      summaryLoading: false,
      exportLoading: false,
      showMore: false,
      // 当前通过汇总卡片筛选的项，用于高亮与再次点击取消
      activeCard: '',
      detailList: [],
      total: 0,
      dateRange: [],
      deptOptions: [],
      subDeptOptions: [],
      summary: {},
      sourceTypeMap: {
        EVECTION: '出差外出',
        LEAVE: '请假调休',
        STOP_MEAL: '停餐申请',
        APPLY_MEAL: '用餐申请',
        FIXED_RULE: '固定配置'
      },
      pickerOptions: {
        shortcuts: [
          { text: '今天', onClick: picker => this.pickDay(picker, 0) },
          { text: '明天', onClick: picker => this.pickDay(picker, 1) },
          { text: '本周', onClick: picker => this.pickWeek(picker) },
          { text: '本月', onClick: picker => this.pickMonth(picker) }
        ]
      },
      queryParams: {
        pageNum: 1,
        pageSize: 20,
        startDate: undefined,
        endDate: undefined,
        staffNo: undefined,
        staffName: undefined,
        diningType: undefined,
        staffScope: undefined,
        staffRole: undefined,
        prDepartmentId: undefined,
        departmentId: undefined,
        sourceType: undefined
      }
    }
  },
  computed: {
    /** 若依在 app 模块维护 device，窗口宽度变化时自动切换 */
    isMobile() {
      return this.$store.state.app.device === 'mobile'
    },
    /**
     * filter 不为空的卡片可点击，点击后按其条件筛选明细列表
     * 仅“内部停餐”“外部用餐”提供快捷筛选：
     *   应就餐、内部就餐为常态数据，逐条查看意义不大；
     *   就餐总数跨内外部，无法用一组条件表达，故均不可点击
     */
    summaryCards() {
      return [
        { key: 'shouldDineNum', label: '应就餐', tip: '排班为工作日的在职人数', filter: null },
        { key: 'innerDineNum', label: '内部就餐', tip: '应就餐减去停餐', filter: null },
        { key: 'stopNum', label: '内部停餐', tip: '点击可筛选当日停餐名单',
          filter: { staffScope: 'HQ', diningType: 'STOP' } },
        { key: 'outerDineNum', label: '外部用餐', tip: '点击可筛选外部来访用餐记录',
          filter: { staffScope: 'EXTERNAL', diningType: 'DINE' } },
        { key: 'totalDineNum', label: '就餐总数', tip: '内部加外部', filter: null }
      ]
    }
  },
  created() {
    this.initDefaultDate()
    this.getDeptOptions()
    this.getList()
    this.getSummary()
  },
  methods: {
    /** 移动端控件统一占满宽度，桌面端使用设计宽度 */
    ctrlStyle(width) {
      return this.isMobile ? { width: '100%' } : { width: width + 'px' }
    },
    hasPermi(permission) {
      const permissions = this.$store.getters && this.$store.getters.permissions
      if (!permissions || permissions.length === 0) {
        return false
      }
      return permissions.indexOf('*:*:*') > -1 || permissions.indexOf(permission) > -1
    },
    /**
     * 默认日期与后端保持一致：
     * 12点前默认今天（对应上午10点报当天），12点后默认明天（对应18点报次日）
     */
    initDefaultDate() {
      const now = new Date()
      const target = new Date()
      if (now.getHours() >= 12) {
        target.setDate(target.getDate() + 1)
      }
      const day = this.formatDate(target)
      this.dateRange = [day, day]
      this.queryParams.startDate = day
      this.queryParams.endDate = day
    },
    formatDate(d) {
      const m = String(d.getMonth() + 1).padStart(2, '0')
      const day = String(d.getDate()).padStart(2, '0')
      return `${d.getFullYear()}-${m}-${day}`
    },
    pickDay(picker, offset) {
      const d = new Date()
      d.setDate(d.getDate() + offset)
      picker.$emit('pick', [d, d])
    },
    pickWeek(picker) {
      const now = new Date()
      const day = now.getDay() || 7
      const start = new Date(now)
      start.setDate(now.getDate() - day + 1)
      const end = new Date(start)
      end.setDate(start.getDate() + 6)
      picker.$emit('pick', [start, end])
    },
    pickMonth(picker) {
      const now = new Date()
      const start = new Date(now.getFullYear(), now.getMonth(), 1)
      const end = new Date(now.getFullYear(), now.getMonth() + 1, 0)
      picker.$emit('pick', [start, end])
    },
    handleDateChange(val) {
      this.queryParams.startDate = val ? val[0] : undefined
      this.queryParams.endDate = val ? val[1] : undefined
    },
    checkRange() {
      const { startDate, endDate } = this.queryParams
      if (!startDate || !endDate) {
        this.$message.warning('请选择查询日期')
        return false
      }
      const days = (new Date(endDate) - new Date(startDate)) / 86400000 + 1
      if (days > 31) {
        this.$message.warning('查询范围最多31天，请缩小日期区间')
        return false
      }
      return true
    },
    getList() {
      if (!this.checkRange()) return
      this.loading = true
      listDiningDetail(this.queryParams).then(res => {
        this.detailList = res.rows
        this.total = res.total
        this.loading = false
      }).catch(() => {
        this.loading = false
      })
    },
    getSummary() {
      if (!this.hasPermi('dining:report:summary')) return
      if (!this.checkRange()) return
      this.summaryLoading = true
      getDiningSummary(this.queryParams).then(res => {
        this.summary = res.data || {}
        this.summaryLoading = false
      }).catch(() => {
        this.summaryLoading = false
      })
    },
    getDeptOptions() {
      if (!this.hasPermi('dining:report:deptOptions')) return
      listDeptOptions().then(res => {
        this.deptOptions = res.data || []
      })
    },
    handlePrDeptChange(val) {
      this.queryParams.departmentId = undefined
      this.subDeptOptions = []
      if (val && this.hasPermi('dining:report:subDeptOptions')) {
        listSubDeptOptions(val).then(res => {
          this.subDeptOptions = res.data || []
        })
      }
    },
    /**
     * 移动端点击问号查看统计口径说明
     * 卡片本身可点击筛选，故需 @click.stop 阻止冒泡，避免同时触发筛选
     */
    showTip(card) {
      this.$alert(card.tip, card.label, { confirmButtonText: '知道了' })
    },
    /**
     * 点击汇总卡片快速筛选明细列表
     * 再次点击同一张卡片取消筛选，恢复全部数据
     * 仅改变人员范围与就餐状态，日期、工号等其余搜索条件保持不变
     */
    handleCardClick(card) {
      if (!card.filter) {
        return
      }
      if (this.activeCard === card.key) {
        this.activeCard = ''
        this.queryParams.staffScope = undefined
        this.queryParams.diningType = undefined
      } else {
        this.activeCard = card.key
        this.queryParams.staffScope = card.filter.staffScope
        this.queryParams.diningType = card.filter.diningType
      }
      this.queryParams.pageNum = 1
      // 卡片数字反映当前日期范围的全貌，不应随明细筛选变化，故只刷新列表不刷新汇总
      this.getList()
    },
    handleQuery() {
      this.queryParams.pageNum = 1
      // 手动搜索时清除卡片高亮，避免高亮状态与实际筛选条件不一致
      this.activeCard = ''
      this.getList()
      this.getSummary()
    },
    resetAll() {
      this.resetForm('queryForm')
      Object.assign(this.queryParams, {
        pageNum: 1,
        staffNo: undefined,
        staffName: undefined,
        diningType: undefined,
        staffScope: undefined,
        staffRole: undefined,
        prDepartmentId: undefined,
        departmentId: undefined,
        sourceType: undefined
      })
      this.subDeptOptions = []
      this.activeCard = ''
      this.initDefaultDate()
      this.handleQuery()
    },
    sourceTagType(type) {
      const map = {
        EVECTION: 'primary',
        LEAVE: 'warning',
        STOP_MEAL: 'danger',
        APPLY_MEAL: 'success',
        FIXED_RULE: 'info'
      }
      return map[type] || 'info'
    },
    /**
     * 三个导出复用同一套日期条件
     * 后端直接写文件流，故用 blob 接收后由浏览器保存
     */
    doExport(uri, tip) {
      if (!this.checkRange()) return
      this.$confirm(`确认导出 ${this.queryParams.startDate} 至 ${this.queryParams.endDate} 的${tip}？`,
        '提示', { confirmButtonText: '确定', cancelButtonText: '取消', type: 'warning' }
      ).then(() => {
        this.exportLoading = true
        return exportDiningFile(uri, {
          startDate: this.queryParams.startDate,
          endDate: this.queryParams.endDate
        })
      }).then(data => {
        const blob = new Blob([data], {
          type: 'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet'
        })
        const link = document.createElement('a')
        link.href = window.URL.createObjectURL(blob)
        link.download = `${tip}_${this.queryParams.startDate}_${this.queryParams.endDate}.xlsx`
        document.body.appendChild(link)
        link.click()
        document.body.removeChild(link)
        window.URL.revokeObjectURL(link.href)
        this.exportLoading = false
      }).catch(err => {
        this.exportLoading = false
        if (err !== 'cancel') {
          console.error('导出失败:', err)
        }
      })
    },
    handleExportDaily() {
      this.doExport('dining/report/export', '每天就餐人数明细表')
    },
```

```vue
      }).catch(() => {
        this.loading = false
      })
    },
    /** 生效状态：综合启用开关与日期区间判断当前是否真正生效 */
    effectTag(row) {
      if (row.status !== '1') {
        return { type: 'info', text: '已停用' }
      }
      const today = new Date()
      today.setHours(0, 0, 0, 0)
      if (row.startDate && new Date(row.startDate) > today) {
        return { type: 'warning', text: '未开始' }
      }
      if (row.endDate && new Date(row.endDate) < today) {
        return { type: 'info', text: '已过期' }
      }
      return { type: 'success', text: '生效中' }
    },
    handleQuery() {
      this.queryParams.pageNum = 1
      this.getList()
    },
    resetQuery() {
      this.resetForm('queryForm')
      this.queryParams.subjectType = undefined
      this.queryParams.ruleType = undefined
      this.queryParams.staffNo = undefined
      this.queryParams.staffName = undefined
      this.queryParams.status = undefined
      this.handleQuery()
    },
    handleSelectionChange(selection) {
      this.ids = selection.map(item => item.id)
      this.single = selection.length !== 1
      this.multiple = !selection.length
    },
    reset() {
      this.form = {
        id: undefined,
        subjectType: 'INNER',
        staffNo: undefined,
        staffName: undefined,
        organizationName: undefined,
        ruleType: 'STOP',
        startDate: undefined,
        endDate: undefined,
        status: '1',
        remark: undefined
      }
      this.termType = 'LONG'
      this.dateRange = []
      this.resetForm('form')
    },
    cancel() {
      this.open = false
      this.reset()
    },
    handleSubjectChange() {
      this.form.staffNo = undefined
      this.form.staffName = undefined
      this.form.organizationName = undefined
      this.$nextTick(() => {
        this.$refs.form && this.$refs.form.clearValidate()
      })
    },
    handleTermChange(val) {
      if (val === 'LONG') {
        this.dateRange = []
        this.form.startDate = undefined
        this.form.endDate = undefined
      }
    },
    handleDateChange(val) {
      this.form.startDate = val ? val[0] : undefined
      this.form.endDate = val ? val[1] : undefined
    },
    handleAdd() {
      this.reset()
      this.open = true
      this.title = '新增固定人员规则'
    },
    handleUpdate(row) {
      this.reset()
      const id = row ? row.id : this.ids[0]
      getFixedRule(id).then(res => {
        this.form = res.data
        if (this.form.startDate || this.form.endDate) {
          this.termType = 'RANGE'
          this.dateRange = [
            this.form.startDate ? this.parseTime(this.form.startDate, '{y}-{m}-{d}') : '',
            this.form.endDate ? this.parseTime(this.form.endDate, '{y}-{m}-{d}') : ''
          ]
        } else {
          this.termType = 'LONG'
          this.dateRange = []
        }
        this.open = true
        this.title = '修改固定人员规则'
      })
    },
    submitForm() {
      this.$refs['form'].validate(valid => {
        if (!valid) return
        if (this.termType === 'RANGE' && (!this.form.startDate || !this.form.endDate)) {
          this.$message.warning('请选择生效区间，或改选长期有效')
          return
        }
        this.submitting = true
        const req = this.form.id ? updateFixedRule(this.form) : addFixedRule(this.form)
        req.then(() => {
          this.$message.success(this.form.id ? '修改成功' : '新增成功')
          this.open = false
          this.submitting = false
          this.queryParams.pageNum = 1
          this.getList()
          this.tipRegenerate()
        }).catch(() => {
          this.submitting = false
        })
      })
    },
    handleDelete(row) {
      const ids = row ? [row.id] : this.ids
      const names = row ? row.staffName : `选中的 ${ids.length} 条`
      this.$confirm(`确认删除 ${names} 的配置？删除后该人员将恢复默认用餐。`, '警告', {
        confirmButtonText: '确定', cancelButtonText: '取消', type: 'warning'
      }).then(() => {
        return Promise.all(ids.map(id => delFixedRule(id)))
      }).then(() => {
        this.queryParams.pageNum = 1
        this.getList()
        this.$message.success('删除成功')
        this.tipRegenerate()
      }).catch(() => {})
    },
    handleStatusChange(row) {
      const text = row.status === '1' ? '启用' : '停用'
      this.$confirm(`确认${text} ${row.staffName} 的配置？`, '提示', {
        confirmButtonText: '确定', cancelButtonText: '取消', type: 'warning'
      }).then(() => {
        return updateFixedRule(row)
      }).then(() => {
        this.$message.success(text + '成功')
        this.tipRegenerate()
      }).catch(() => {
        row.status = row.status === '1' ? '0' : '1'
      })
    },
    /** 配置变更后需重新汇算才会体现到就餐数据，此处给出提示 */
    tipRegenerate() {
      this.$notify({
        title: '配置已保存',
        message: '定时任务将在下个整点自动汇算；如需立即生效，请点击"立即汇算"',
        type: 'info',
        duration: 5000
      })
    },
    handleGenerate() {
      this.$confirm('将按当前配置重新生成上1个月至未来2个月的就餐数据，确认执行？', '提示', {
        confirmButtonText: '确定', cancelButtonText: '取消', type: 'warning'
      }).then(() => {
        this.generating = true
        return generateFixedRule()
      }).then(res => {
        this.generating = false
        // 用 alert 而非轻提示：汇算结果需用户确认知晓
        this.$alert(res.msg || '汇算完成', '汇算结果', {
          confirmButtonText: '知道了', type: 'success'
        })
      }).catch(err => {
        this.generating = false
        if (err !== 'cancel') {
          console.error('立即汇算失败:', err)
          this.$message.error('汇算失败：' + (err.msg || err.message || '请查看控制台'))
        }
      })
    }
  }
}
</script>
```

## 汇总卡片快捷筛选

### 交互说明

点击汇总卡片即可按该口径筛选下方明细列表，省去手动选择两项筛选条件的操作。

| 卡片         | 是否可点击 | 点击后的筛选条件                 |
| ------------ | ---------- | -------------------------------- |
| 应就餐       | 否         | ——                               |
| 内部就餐     | 否         | ——                               |
| **内部停餐** | **是**     | 人员范围=内部员工，就餐状态=停餐 |
| **外部用餐** | **是**     | 人员范围=外部人员，就餐状态=就餐 |
| 就餐总数     | 否         | ——                               |

可点击的卡片鼠标移入显示手型；点击后卡片高亮并在标题右侧出现关闭图标， **再次点击同一张卡片即取消筛选**，恢复全部数据。

### 三点实现要点

**一、只刷新列表，不刷新汇总。** `handleCardClick` 中只调 `getList()`，不调 `getSummary()`。 汇总数字反映的是当前日期范围内的全貌，不应随"正在看哪一类"而变化—— 若一并刷新，点击"内部停餐"后其余四个数字都会变成 0，数据失去参照意义。

**二、只覆盖两项条件，其余保留。** 点击卡片仅设置 `staffScope` 与 `diningType`， 日期范围、工号、姓名、部门等条件保持不变，便于在已有筛选基础上继续下钻。

**三、两处需清除高亮状态。** `handleQuery()`（手动点搜索）与 `resetAll()`（重置）中都要将 `activeCard` 置空， 否则用户手动改了筛选条件、卡片却仍高亮，会造成误导。

### 为何另外三张不可点击

- **应就餐、内部就餐**：属常态数据，逐条查看意义不大，用户反馈中也未提出需求；
- **就餐总数**：等于"内部就餐 + 外部用餐"，跨越了人员范围， 无法用单组 `staffScope` + `diningType` 条件表达，故不提供点击， 避免用户点击后无反应而误以为功能异常。

## 响应式适配说明（电脑端 / 手机端）

### 适配思路

两个页面均在**同一份代码内**同时支持桌面与移动端，不做两套页面。核心是一个计算属性：

```js
computed: {
  /** 若依在 app 模块维护 device，窗口宽度变化时自动切换 */
  isMobile() {
    return this.$store.state.app.device === 'mobile'
  }
}
```

若依自带 `ResizeMixin`，浏览器宽度小于 992px 时会自动把 `device` 置为 `mobile`， 因此手机访问、或电脑上把窗口拖窄，都会即时切换，无需额外监听。

### 各区块的适配方式

| 区块         | 桌面端                                   | 移动端                                            |
| ------------ | ---------------------------------------- | ------------------------------------------------- |
| 搜索表单     | 行内排列（`inline`），控件定宽           | 标签置顶（`label-position="top"`），控件宽度 100% |
| 汇总卡片     | 一行铺开 5 个（`:lg="4"`），说明常驻显示 | 每行 2 个（`:xs="12"`），说明改为问号图标点击弹出 |
| 导出按钮     | 横向排列，右侧带口径提示                 | 三个按钮等分一行，提示独占下方一行并缩小字号      |
| **数据展示** | **表格**                                 | **卡片列表**                                      |
| 分页         | 完整（含每页条数、跳转）                 | 精简（`total, prev, pager, next`）                |
| 弹窗         | 固定 560px                               | 宽度 92%、顶部 5vh，内容区可滚动                  |
| 表单弹窗标签 | 右对齐、96px                             | 置顶、自适应                                      |

### 为什么移动端改用卡片而非表格

就餐明细有 10 列、配置表有 10 列，手机屏幕宽度不足 400px， 表格只能横向滚动，需要反复左右拖动才能看全一行，极易看错行。

卡片列表把一条记录竖向展开：**头部**放姓名与状态标签（最关键的两项一眼可见）， **主体**按「标签 + 值」逐行列出，**底部**放操作按钮。 配置页的卡片底部直接内嵌了启用开关与修改、删除按钮， 因此移动端隐藏了依赖多选的批量按钮，避免在触屏上勾选复选框。

### 控件宽度的统一处理

搜索区每个控件的宽度由一个方法统一给出，避免在模板里写死：

```js
/** 移动端控件统一占满宽度，桌面端使用设计宽度 */
ctrlStyle(width) {
  return this.isMobile ? { width: '100%' } : { width: width + 'px' }
}
```

模板中写 `:style="ctrlStyle(150)"` 即可，两端各自生效。

### 移动端的说明性文字不可简单隐藏

初版为节省版面，移动端隐藏了卡片下方的口径说明与导出按钮旁的提示， 实测用户反馈"看不到说明容易理解错"，故调整为：

| 内容                                                | 移动端处理                                 |
| --------------------------------------------------- | ------------------------------------------ |
| 卡片口径说明（如"应就餐 = 排班为工作日的在职人数"） | 标题旁显示问号图标，点击弹出 `$alert` 说明 |
| 导出口径提示（两套统计口径的差异）                  | 保留显示，独占按钮下方一行，字号缩至 11px  |

问号图标必须加 `@click.stop`：卡片本身可点击筛选，不阻止冒泡会在查看说明的同时触发筛选。

```vue
<i v-if="card.tip && isMobile" class="el-icon-question card-help"
   @click.stop="showTip(card)"></i>
/**
 * 移动端点击问号查看统计口径说明
 * 卡片本身可点击筛选，故需 @click.stop 阻止冒泡，避免同时触发筛选
 */
showTip(card) {
  this.$alert(card.tip, card.label, { confirmButtonText: '知道了' })
}
```

同时为"内部停餐""外部用餐"两张可点击卡片补充了 `tip` 文案 （"点击可筛选当日停餐名单""点击可筛选外部来访用餐记录"）， 桌面端常驻显示，移动端点问号查看，两端用户都能知道这两张卡片可以点。

### 注意事项

1. **`>>>` 深度选择器**：`<style scoped>` 中修改 Element UI 内部元素（如 `.el-form-item__label`） 必须用 `>>>`，否则 scoped 会使样式不生效。若项目使用 sass/less，需改为 `::v-deep`。
2. **弹窗高度**：移动端表单较长，已限制 `.el-dialog__body` 最大高度 68vh 并允许滚动， 否则底部的确定、取消按钮会被挤出屏幕。
3. **卡片列表无需分页组件改造**：分页组件本身自适应，仅通过 `layout` 精简了显示项。
4. **测试方式**：电脑浏览器按 F12 打开设备模拟，或直接把窗口宽度拖到 992px 以下， 即可看到布局自动切换，无需真机。
